========================================================
  안경원 정산 자동화 - 사용법
========================================================


[1] 매달 하는 일  (4단계)
--------------------------------------------------------

  1. 신한카드 홈페이지에서 지난달 이용내역을 엑셀로 받는다
     -> "02_카드내역" 폴더에 넣는다

  2. 신한은행 SMS 알림을 스크린샷으로 찍는다
     -> "05_계좌내역" 폴더에 넣는다
     ※ 이 사진은 프로그램이 못 읽습니다. Claude Code 에게
       "계좌 스크린샷 옮겨줘" 라고 부탁해야 합니다.

  3. 그 달 일일결산 엑셀을 "06_매출" 폴더에 넣는다
     파일명은 "2026년 7월.xlsx" 처럼 연월이 들어가야 합니다

  4. "실행" 파일을 더블클릭한다
     -> 까만 창이 뜨고 5초쯤 뒤 대시보드가 자동으로 열립니다
     -> 까만 창은 아무 키나 누르면 닫힙니다


[2] 분류를 고치고 싶을 때
--------------------------------------------------------

  03_데이터 > 거래처마스터.xlsx 를 엽니다.

  - "분류" 칸을 드롭다운에서 고르면 됩니다
  - "결제주기" 칸: 월말에 전월분을 몰아서 내면 "전월분",
    그 자리에서 바로 결제하면 "당월분"
  - 고친 뒤 "실행" 을 다시 누르면 반영됩니다


[3] 매달 나가는 고정비를 넣고 싶을 때
--------------------------------------------------------

  03_데이터 > 월고정비.xlsx 에 줄을 추가합니다.
  항목 / 분류 / 월금액 세 개만 적으면 됩니다.

  지금 들어 있는 것:
    퇴직금 충당 (김상기)   인건비     283,333원
    대출이자              금융비용   625,000원


[4] 대시보드에 비밀번호를 걸고 싶을 때
--------------------------------------------------------

  03_데이터 폴더에 "비밀번호.txt" 파일을 만들고
  원하는 비밀번호만 적어서 저장한 뒤 "실행" 을 누릅니다.

  내용이 암호로 잠기기 때문에, 파일을 열어 소스를 봐도
  알아볼 수 없습니다. 비밀번호를 없애려면 그 파일을 지우면 됩니다.

  ※ 대시보드만 잠깁니다. 03_데이터 폴더의 엑셀은 그대로 열립니다.
    정말 감추려면 AI 폴더 자체를 개인 위치로 옮기세요.


[5] 다른 컴퓨터(집)에서 이어서 쓰려면
--------------------------------------------------------

  A. 폴더 옮기기
     "AI" 폴더 전체를 통째로 복사합니다 (약 70MB).
     - USB 로 옮기거나
     - 구글 드라이브 / 원드라이브 같은 클라우드에 넣으면
       양쪽 컴퓨터가 자동으로 같은 내용을 봅니다 (추천)

  B. 처음 한 번만 - 준비하기
     옮긴 폴더에서 "설치" 파일을 더블클릭합니다.
     Python 이 없다고 나오면 화면에 뜬 주소에서 내려받아
     설치한 뒤 다시 "설치" 를 누릅니다.
     설치할 때 "Add python.exe to PATH" 를 꼭 체크하세요.

  C. Claude Code 로 이어서 작업하기
     집 컴퓨터에도 Claude Code 를 설치한 뒤,
     "AI" 폴더를 열고 대화를 시작하면 됩니다.
     이 폴더의 CLAUDE.md 파일에 지금까지의 맥락이 다 적혀 있어서
     처음부터 설명하지 않아도 이어서 작업할 수 있습니다.


[6] 폴더 설명
--------------------------------------------------------

  01_영수증      거래명세표 사진 (대사 기능은 아직 준비 중)
  02_카드내역    신한카드 이용내역 엑셀
  03_데이터      거래처마스터 / 월고정비 / 계좌내역 / 원장
  04_리포트      월별 정산리포트 (자동 생성)
  05_계좌내역    은행 SMS 스크린샷
  06_매출        일일결산일지 엑셀  <- 매출은 여기서만 가져옵니다
  scripts        프로그램 본체 (건드리지 마세요)

  실행.bat       매달 누르는 파일
  설치.bat       새 컴퓨터에서 최초 1회만
  대시보드.html  결과 화면
  CLAUDE.md      Claude Code 가 읽는 설명서


[7] 알아두면 좋은 것
--------------------------------------------------------

  - 매출은 "06_매출" 엑셀에서만 가져옵니다.
    통장에 들어온 돈은 카드 수수료와 시차 때문에 매출과 다릅니다.
    그래서 통장 입금은 "참고" 로만 보여줍니다.

  - 미수(외상)는 매출에서 뺐습니다. 받는 날 매출로 잡힙니다.

  - 거래처/임대료/인건비는 다음 달에 결제되기 때문에,
    한 달이 완성되려면 그 다음 달 자료까지 필요합니다.
    그래서 8월 손익은 9월 자료가 나와야 볼 수 있습니다.

  - "귀속 기준" 은 그 달에 발생한 것, "결제 기준" 은 그 달에
    실제로 돈이 오간 것입니다. 순이익은 귀속 기준이 맞습니다.
